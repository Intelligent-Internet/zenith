# OpenCode Support Documentation

OpenCode support is split by audience so setup, operations, and development
guidance can stay focused:

- [User guide](user.md): install OpenCode, initialize a project, and start a
  Zenith mission from OpenCode.
- [Admin guide](admin.md): understand generated configuration, preservation
  rules, security boundaries, and operational checks.
- [Developer guide](developer.md): maintain the PR-A implementation, tests,
  assets, and future PR-B/PR-C boundaries.
